# 単語カードPDFメーカー (wordcard-pdf)

CSVファイルから、両面印刷でぴったり重なる単語カードPDFをブラウザ上で作成・ダウンロードできるWebアプリケーションです。

🌐 **Webサイト**: [https://tyama11.github.io/wordcard-pdf/](https://tyama11.github.io/wordcard-pdf/)

---

## 特長

- **CSVだけでPDF**: 表と裏のテキストを並べたCSVファイルを用意するだけで、名刺サイズの単語カードPDFを瞬時に生成します。
- **表裏ずれ対策と自動テスト**: プリンタ特有の両面印刷のズレを解消する0.1mm単位のオフセット補正機能と「位置合わせシート」を搭載。表裏の位置合わせ精度は自動テストにより検証されています。
- **数式・化学式対応**: MathJax（mhchem拡張）を組み込んでおり、本格的なLaTeX数式（`$...$`, `$$...$$`）や化学反応式（`\ce{...}`）をきれいにレンダリングします。
- **文字サイズ自動縮小**: 文字数に合わせてフォントサイズを6px〜48pxの範囲で自動調整し、カード枠（91×55mm）からはみ出さないようきれいに収めます。
- **データは外部送信しない**: すべての処理はブラウザ内で完結します。入力した単語データが外部サーバーへ送信されることは一切ありません。

---

## 使い方（3ステップ）

1. **Step 1: CSVを選ぶ**  
   CSVファイルをドラッグ＆ドロップするか、「ファイルを選択」ボタンから読み込みます。読み込むと、カードの枚数と必要なA4用紙の枚数が表示されます。
2. **Step 2: 印刷設定**  
   とじ方（長辺とじ推奨/短辺とじ）、裏面のずれ補正（X/Y）、トンボ（裁断マーク）の有無を設定します。必要に応じて「位置合わせシート」を印刷してズレを測定できます。
3. **Step 3: PDFを作る**  
   「PDFを作成してダウンロード」ボタンをクリックすると、プログレスバーが表示され、完了後に `wordcards-YYYYMMDD-HHmm.pdf` が自動でダウンロードされます。

## CSVの書き方

### 列の仕様と文字コード

- **列の構成**: 1列目が「表面」、2列目が「裏面」になります。3列目以降は無視され、空行は自動的にスキップされます。
- **ヘッダー行**: 任意です。1行目が `表|裏`, `表面|裏面`, `front|back`, `question|answer`, `問題|答え`, `word|meaning`, `単語|意味` に一致する場合はヘッダーとして自動認識し、カードからは除外されます。ヘッダーなしのCSVもそのまま利用可能です。
- **文字コード**: UTF-8（BOM付き/BOMなし）またはShift_JISに対応しています（自動判別）。Microsoft Excelで保存する場合は「**CSV UTF-8 (コンマ区切り) (.csv)**」を推奨します。
- **セル内改行・特殊文字**: セル内の改行はカード上でもそのまま改行として表示されます。カンマや改行を含むセルは、RFC 4180に準拠してダブルクォーテーション `"` で囲んでください。

### 例

```csv
表,裏
apple,"リンゴ, くだもの"
"温故知新","過去の事実を研究して、
そこから新しい知恵や見解を導き出すこと。"
ephemeral,つかの間の・儚い
$\frac{d}{dx}x^n$,$n x^{n-1}$
\ce{H2SO4},硫酸
```

## 数式・化学式の書き方

テキスト中にLaTeX形式の数式や化学式を直接記述できます。

| 書き方 | 意味・表示例 | 説明 |
|---|---|---|
| `$x^2$` | $x^2$ | インライン数式（上付き添字・累乗） |
| `$\frac{a}{b}$` | $\frac{a}{b}$ | 分数 |
| `$\sqrt{x}$` | $\sqrt{x}$ | 平方根（ルート） |
| `$$...$$` | 独立行数式 | ディスプレイ数式（中央に大きく表示） |
| `\ce{H2O}` | $\text{H}_2\text{O}$ | 化学式（水） |
| `\ce{2H2 + O2 -> 2H2O}` | $2\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$ | 化学反応式 |
| `\ce{Fe^{3+}}` | $\text{Fe}^{3+}$ | イオンの電荷 |
| `\ce{A <=> B}` | $\text{A} \rightleftharpoons \text{B}$ | 化学平衡反応 |
| `\$` | $ | 半角ドル記号そのものの表示 |

> [!NOTE]
> `\(...\)`（インライン数式）および `\[...\]`（ディスプレイ数式）の記述方法も利用可能です。

## 印刷のしかた

両面印刷をきれいに揃えるため、プリンタの印刷ダイアログで以下の設定を必ず確認してください。

- **用紙サイズ**: `A4`（縦向き）
- **両面印刷**: `有効（長辺とじ）` ※アプリ側で短辺とじを選んだ場合は短辺とじ
- **倍率**: **「実際のサイズ」** または **「100%」**
- **「ページに合わせる / 用紙に合わせる」**: **必ずOFF**（拡大・縮小されると位置がずれます）
- **「フチなし印刷」**: **必ずOFF**（用紙端に合わせて全体が引き伸ばされます）
- **推奨用紙**:
  - **A4 10面 名刺用ミシン目用紙**: 91×55mm、1シート10枚（上下余白11mm、左右余白14mm）。市販の名刺用紙にそのまま印刷して切り離せます。
  - **普通紙 + カッター裁断**: トンボ（裁断マーク）印刷をONにして普通紙に印刷し、定規とカッターでカットします。

## ずれ補正の手順

プリンタの給紙機構によって発生する表裏の印刷位置ズレを、0.1mm単位で補正できます。

1. アプリのStep 2にある **「位置合わせシートをダウンロード」** ボタンを押し、2ページのテストPDFを出力します。
2. 本番と同じ用紙・印刷設定（A4・両面長辺とじ・倍率100%）で印刷します。
3. 印刷された用紙を蛍光灯などの光に透かして見ます。表面の十字線に対し、裏面の目盛り付き十字線がどのくらいずれているか（mm単位）を読み取ります。
4. 読み取った数値をアプリの **「裏面オフセット X」** および **「裏面オフセット Y」** に入力します（入力範囲: -5.0mm 〜 +5.0mm）。
5. **正負の向き（裏面を見たときの向き）**:
   - **+X**: 裏面の印刷位置を **右へ** 動かします（-X は左へ）
   - **+Y**: 裏面の印刷位置を **下へ** 動かします（-Y は上へ）

### 短辺とじプリンタの場合

お使いのプリンタが短辺とじ両面印刷のみに対応している場合や、手動両面印刷で短辺反転給紙を行う場合は、Step 2のとじ方設定で **「短辺とじ」** を選択してください。裏面のカード配置が上下反転マッピングされ、正しく印刷されます。

## よくある質問（FAQ）

### Q. 文字が小さくなってしまいます
長文のテキストがカード枠（91×55mm、内側余白4mm）からはみ出さないよう、フォントサイズが自動的に縮小（最小6pxまで）されます。文字を大きく表示したい場合は、適宜文章を短くするか改行を調整してください。

### Q. 数式が赤い文字でそのまま表示されます
LaTeXまたはmhchemの記法にエラー（構文ミスや閉じ括弧の欠落など）があります。エラー箇所は赤字で元のテキストが表示されます。なお、PDF生成処理自体は中断されずに最後まで作成されます。

### Q. スマートフォンでも使えますか？
本アプリはレスポンシブWebアプリとして設計されており、スマートフォンやタブレットのブラウザでも動作します。ただし、印刷ダイアログで「倍率100%（原寸）」を正確に指定する必要があるため、PCからの印刷を推奨します。

### Q. 表裏の位置がどうしてもずれてしまいます
1. 印刷設定で「ページに合わせる」がOFFになっているか、「倍率100% / 実際のサイズ」になっているか、「フチなし印刷」がOFFになっているかを再確認してください。
2. それでもずれる場合はプリンタの給紙による固有のズレですので、「位置合わせシート」を使ってズレ量を測定し、「裏面オフセット X / Y」に数値を入力して微調整してください。
