単語カードPDFメーカー

CSVファイルから両面印刷用の単語カードPDFを生成するWebツールです。

CSVはブラウザ内だけで処理され、どこにも送信されません

Step 1: CSVを選ぶ

ここにファイルをドラッグ＆ドロップ、または

サンプルCSVをダウンロード
CSVの形式・書き方について
  • 1列目を表面（表）、2列目を裏面（裏）として読み込みます（3列目以降は無視されます）。
  • 1行目のヘッダーは自動検出されます（表|裏、front|back、問題|答え など）。
  • 文字コードは UTF-8（BOM付き/なし）および Shift_JIS に対応しています（自動判定）。
  • セル内に改行やカンマを含む場合は、RFC 4180 規格に従いダブルクォートで囲んでください。

Step 2: 印刷設定

裏面を見たとき、+X は裏面を右へ、+Y は裏面を下へ移動します（-X は左へ、-Y は上へ移動）。

両面印刷した位置合わせシートを光に透かし、表の十字が裏の目盛りのどこに見えるかを読み取ります。読み取った値を、今の補正値に足して入力してください（裏面を見て +X＝右、+Y＝下）。

Step 3: PDFを作る

0 / 0 面を作成中

印刷時の注意

  • 用紙サイズ: A4
  • 倍率設定: 「実際のサイズ」または「100%」を選択してください（「ページに合わせる / 用紙に合わせる」は必ずOFF）。
  • 両面印刷: 「両面印刷・長辺とじ」に設定してください。
  • フチなし印刷: 「フチなし印刷」はOFFにしてください（拡大されて位置がずれます）。
数式・化学式の書き方（TeX・mhchem記法チートシート）

セル内のテキストに以下の記法を埋め込むことで、数式や化学式をきれいに表示できます。

  • インライン数式: $式$ または \(式\)
  • 独立行数式（センタリング）: $$式$$ または \[式\]
  • 化学式・反応式: \ce{式}（数式の外でもそのまま記述できます）
  • 通常のドル記号（半角）: \$
書き方（例） 説明
$x^2$上付き添字・累乗
$\frac{a}{b}$分数
$\sqrt{x}$平方根（ルート）
$$...$$独立行数式（センタリング表示）
\ce{H2O}化学式（水）
\ce{2H2 + O2 -> 2H2O}化学反応式
\ce{Fe^{3+}}イオン電荷
\ce{A <=> B}平衡反応の矢印
\$半角ドル記号の表示
